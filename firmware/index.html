Installing it

A unit checks this page for itself, hourly by default, and shows a notice on its own dashboard when a build is waiting. Press Install there, after reading what it contains.

To point a unit here by hand, or to a different build:

GET http://spenser.local/setSettings?updateUrl=https://costateixeira.github.io/spenser/firmware/manifest.json&updateCheckHours=1
POST http://spenser.local/ota/check
POST http://spenser.local/ota/install

Those need the unit's key, as X-Spenser-Key. To push an image at a unit instead, without a manifest:

curl -X POST -H "X-Spenser-Key: $KEY" --data-binary @firmware.bin \
  http://spenser.local/ota/firmware

The filesystem image carries the dashboard and the agent guide, so install it when those change. A unit keeps the image it was running and can roll back to it.
