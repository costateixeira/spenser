Uitbreiding: Dispensing device

Officiële URL: http://costateixeira.github.io/spenser/StructureDefinition/dispensingDevice Versie: 1.0.0
Active vanaf 2026-11-13 Naam: DispensingDevice

The Spenser unit that is to dispense this order, named by a logical reference: the unit's identifier in http://costateixeira.github.io/spenser/unit, which is its name, Spenser- and the last two bytes of its factory MAC.

R5 has no element on MedicationRequest for this. MedicationRequest.performer and MedicationRequest.device take a DeviceDefinition, a kind of device, and dispenseRequest.dispenser takes only an Organization. A logical reference needs nothing on the server: the unit does not have to be registered as a Device for the order to name it.

When a Task makes the order actionable, a Device in Task.requestedPerformer takes precedence over this extension. On an order with no Task, or a Task that names no unit, a unit acts on this extension: it skips an order that names another unit.

Context of Use

    Deze extensie kan worden gebruikt op de volgende element(en)

    • Element-id: MedicationRequest

Usage info

Gebruik:

  • Gebruik Extensie: SpenserRequest
  • Voorbeelden voor Extensie: MedicationRequest/ActionableDarkOrderForOneUnit and MedicationRequest/PlainDarkOrderForOneUnit
