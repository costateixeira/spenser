# Translations - Spenser - a developer's companion v1.0.0

## Translations

This guide is written in English, which is the version that counts. The Portuguese, Dutch and French pages were translated from it by an AI and have not yet been reviewed by a native speaker, so where a translation and the English disagree, trust the English.

Code, FHIR element names and the labels on a unit's own dashboard stay in English in every language.

If a translation is wrong or reads badly, please [open an issue](https://github.com/costateixeira/spenser/issues), saying which page and which language.
