Order a chocolate

Places the order on the FHIR server, addressed to one Spenser. That unit picks it up on its next poll, wherever it is.

A unit's name is the Wi-Fi network it shows in setup mode: Spenser- and the last four characters of its MAC address.

    Every waiting order will be dispensed by some unit. A Task that names no unit goes to the first unit that claims it.
